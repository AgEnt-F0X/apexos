## 2. Findings & fixes made during this audit

1. **Evaluation-instant bug (real, would-have-shipped):** final-order checks evaluated at
   `tMax − 30s`. Telemetry channels can run into cool-down laps past the chequed flag while
   OpenF1 position rows freeze per-driver → stale-order soup (Interlagos showed
   `NOR → RUS → TSU`, an earlier race state). **Fix:** evaluate at the last live position
   sample (`positions.t[last]`). Applied in `verify-pack.ts` + `upgrade-packs.ts`.
   *Lesson recorded:* never evaluate "final state" from telemetry extent; derive it from
   the position log's own end-of-life.
2. **Duplication risk:** results-row normalization existed identically in the loader and the
   migration script. Extracted to `normalizeResults()` (`sessionLoader.ts`), script imports it.
3. **Dead style hook:** `.dossier__cursor` referenced but undefined → now pins the cursor
   readout to the panel floor (`margin-top:auto`).
4. **Stale plan ledger:** §1.1 endpoint matrix still listed `session_result` under "to add";
   replaced with a status column reflecting reality.

## 3. Known deviations (documented, accepted)

- **Corner counts vs official T-numbers:** curvature detection finds 11 @ Interlagos (official
  15) and 22 @ Monaco (official 19). These are data-derived numbers — consistent within our
  model, not FIA-numbered. Fine for plaques/annotations. If we ever display "Turn 8" as an
  official designation, add a curated per-circuit mapping instead of trusting detection.
- **Old browser caches hold v3 packs:** backward-compat decode serves them with empty
  `results`; Dossier gracefully degrades (team-only header line). They self-heal when the
  user re-loads a session (loader fetches fresh → v4). An IndexedDB version bump could
  force-invalidate — deferred as unnecessary churn.
- **Overnight scripts were blocked** (no approvals): full re-snapshot via
  `snapshot-session.ts` timed out at the 2-min harness cap by design — it politely re-pulls
  ~500k rows. The fast path is `upgrade-packs.ts` (one small request per pack), which is why
  it exists.
